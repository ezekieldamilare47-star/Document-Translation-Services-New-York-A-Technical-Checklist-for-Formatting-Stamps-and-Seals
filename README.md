## County Clerk Filings and Name Changes

County clerks across the five boroughs handle marriage records, name changes and business filings. Translated certificates used for these filings need names and dates that match every other record the clerk will see. Sharing the exact passport spellings with the translator at the start, and translating related certificates together, avoids follow-up questions and keeps records consistent.
